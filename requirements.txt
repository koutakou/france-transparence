# Dépendances des pipelines, FIGÉES à la version exacte (`==`), transitives
# comprises. Une version ne change qu'au fil d'une proposition de fusion
# (Dependabot, .github/dependabot.yml), qui passe par le check `construire`.
#
# Pourquoi figer : avec des bornes basses (`duckdb>=1.3`), chaque nouvelle
# venv installait la dernière version publiée. DuckDB 2.0 (21/10/2026) a
# retiré `fetchone()` des relations ; la CI l'a installé d'elle-même et tous
# ses cycles ont échoué à partir du 22/10, sans qu'aucune ligne du dépôt ait
# changé. Le test pipelines/tests/test_dependances.py refuse une ligne non
# figée et une venv qui ne correspond pas à ce fichier.
#
# Contrainte de plateforme : ce fichier doit s'installer sur CPython 3.10 et
# 3.14, Linux x86_64 et macOS arm64. DuckDB 2.0 exige Python >= 3.11 (aucune
# roue cp310) : la dernière version installable partout est 1.5.6. Ne monter
# DuckDB en 2.x qu'une fois vérifié l'interpréteur de la venv du serveur
# (docs/ACTIONS-HUMAINES.md). Le code et les tests passent sous 1.5.6 et 2.0.0.
